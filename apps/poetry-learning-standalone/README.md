# 诗行万里 · 学习平台 v0

完全自包含的静态原型，展示“宋版书页 × 山水行旅 × 现代学习工具”的设计骨架与关键交互占位。

## 打开
直接双击 `index.html` 即可浏览；也可在本目录运行：
```powershell
npm run check
python -m http.server 4173
```
然后打开 http://127.0.0.1:4173。

## v0 范围
- 五个入口：首页、学习路径、诗篇精读、练习、今日复习。
- 首页路径卡片可点击切换；顶部导航与 CTA 可切换页面。
- 右下角 `Tweaks` 面板提供 3 种原子视觉变体与两种信息密度。
- 练习、复习、推荐等业务功能使用明确占位，不伪造数据。
- 内容切片来自仓库已有唐宋诗词语料和审核行旅数据；无网络热链。
