# 唐代零 person-event 诗人手工补采证据

## 1. 范围与红线

- 对象：贺知章、张继、常建、祖咏、上官仪、张志和、聂夷中，共 7 人。
- 快照日期：2026-08-09。
- 本批只生成候选证据，不写入 `data/reviewed/`，不改现有 pipeline、status、coverage、registry，也不触碰 `output/`。
- `event_candidate` 的必要条件：**同一 `source_record_id` 内，时间表达与地点表达共同指向同一个生平事件**。只有籍贯、官名、作品地名，或时间与地点虽同页但分属两个事件时，均降为 `clue_only`；身份冲突或地名映射冲突标 `needs_manual_review`。
- 未把籍贯当作活动地，未把科举年份和无年任所拼成同一年事件，未把不同来源的时间与地点合并成路线。

## 2. 字段与等级

JSONL 每行均含：`poet`、`dynasty`、`source_name`、`source_url`、`source_type`、`source_record_id`、`accessed_at`、`identity_basis`、`time_expression`、`place_expression`、`event_summary`、`evidence_excerpt`、`evidence_locator`、`fact_grade`、`candidate_status`、`notes`。

- `B`：官方/学术数据库的明确身份记录，或有稳定卷次定位的正史、唐人碑铭、总集/文献原文。
- `C`：机构 authority 中转引的现代说明、DataWiki 说明或地名辅助记录；可作线索，仍需回原典。
- `D`：同名候选未消歧，当前只用于阻止错误自动绑定。
- `A` 保留给项目审核层，本批候选不使用。

## 3. 来源与访问说明

优先使用了 [CBDB 官方项目/SQLite](https://github.com/cbdb-project/cbdb_sqlite)、[DILA 人名规范资料库](https://authority.dila.edu.tw/docs/services/person_query.php)、[DILA 地名规范资料库](https://authority.dila.edu.tw/docs/services/place_query.php)、[Chinese Text Project](https://ctext.org/tools/linked-open-data)、维基文库中的公版正史/总集转录。上海图书馆开放数据需要 API key，已有逐人 URI 仅在其页面可稳定返回时才适合补入；本文件没有把未取到正文的页面写成事实证据。

CText 正文页在部分请求中触发人机验证，因此条目同时保留稳定的章节 URL、URN/章节号及短引文定位；正史与碑铭关键条目另用同一公版文本的维基文库转录复核。所有短引文只用于定位，不替代整段原文复核。

## 5. 需要人工复核的重点

1. **常建**：CBDB 94489、147391、149973、163667 四个唐代同名候选。CText DataWiki 指向 94489 只是一条 crosswalk，不能覆盖本地全库审计；需核对“开元进士—盱眙尉—《常建诗》作者”联合键。
2. **祖咏**：DILA/CText 都记开元十三年迁汝坟，但现代落点说明有河南叶县与安徽阜阳等冲突。事件可保留历史地名，坐标暂空。
3. **张继**：项目审计以 CBDB 93495 为唯一映射；互联网聚合条目存在其他“张继”ID。任何合并都须同时满足唐代、字懿孙、襄州、洪州官历与诗作锚点。
4. **聂夷中**：籍贯有河东、河南、河南中都异文；只把“咸通中为华阴尉”作为约年候选，不用871登第年替代任职年。
5. **上官仪**：目前没有同一原始记录同时给出死亡时间和地点，保持线索状态；不根据帝王行在推断事发地。
6. **贺知章**：归乡事件的地点规范化来自同一《旧唐书》人物传开篇“会稽永兴人”与末段“还乡里”，仍需在路线层标明“同传内解析”，不要伪装成原句直接写“到会稽”。

## 6. 下游接入建议

- 先把 7 条 `event_candidate` 送入人工审核队列，不直接并入 reviewed。
- 历史地名解析与现代坐标分开存储；没有坐标不影响保留文本事件。
- 对同一事件的多源复本去重时，以 `(poet, normalized_time, historical_place, event_type)` 为候选键，并完整保留每个 `source_record_id`。
- 前端路线若遇 `needs_manual_review` 或缺坐标，应显示证据卡或“地点待考”，而不是自动补线。
