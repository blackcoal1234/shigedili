# Agent UI Motion Lab 动画实验室设计

日期：2026-07-30

## 设计系统

- 颜色：沿用暖纸、近黑、朱砂、玉色、蓝色；不新增无语义色相。
- 字体：沿用现有中文无衬线界面字体和楷体诗文，不引入联网字体。
- 间距：沿用现有 4/8px 节奏，不改变主要首屏信息密度。
- 圆角：保持 4–8px；印章、节点和主播放按钮可使用圆形。
- 阴影：仅在运动中的纸页、抵达印章和选中证据上使用两级轻阴影。
- 运动曲线：主转场使用 `cubic-bezier(.2,.8,.2,1)`；反馈 120–220ms；镜头 480–1050ms；长行旅仍由真实路线距离决定。
- Motion Lab：顶部提供“克制 / 电影 / 实验”三档与动画开关，偏好保存在 `localStorage`；关闭或 `prefers-reduced-motion` 时所有内容立即稳定呈现。

## 组件设计

### 1. Motion Lab 控制层

新增纯前端偏好模块和控制条。根容器写入 `data-motion-profile`，三个主组件通过同一偏好读取动画档位。控制条只改变表现，不改变 Tool 请求、选中诗人、当前幕或数据。

### 2. 水墨行旅

保留现有 `idle → travelling → arrived → revealing → waiting` 状态机与史料路线限制。

- 行旅：已支持的路线段逐笔变为完成色，舟、马、车、步行或未载方式标记只沿 Tool 坐标插值移动。
- 抵达：地图轻微聚焦，地点印章落下，再显示年份、地点、来源、诗题和逐字诗文。
- 档位：克制档只保留路线和淡入；电影档加入镜头聚焦、纸幕和印章；实验档加入节点余波与路线墨迹扩散。
- 无史料连续段时继续直接切换，并显示现有缺口提示，不制作虚构路线。

### 3. 电影卷轴

将 `PoemScenePlayer` 扩展为 `settled → covering → swapping → revealing → settled` 状态机。

- 暖纸遮幅完全覆盖时才交换场景索引，确保外部证据面板与可见内容同步。
- 年份、地点、标题、2–4 行诗句、事件和情绪证据按层次揭示；完整 `read_seconds` 从揭示完成后开始。
- 下一幕与自动播放正向，上一幕镜像；转场中锁定重复导航；暂停保留停驻剩余时间。
- 移动端改为垂直纸张擦拭，不移动整个纵向页面。

### 4. 意象潮汐

保留 ECharts 唐宋真实率值和证据句。

- 选择词时，旧柱形退场、新值以双潮线/柱形混合过渡进入；数字滚动至真实值。
- 证据句按朝代分组错峰出现，唐宋颜色只承担现有语义。
- 克制档使用 ECharts 更新动画；电影档增加潮线和聚焦；实验档增加词形余波，但不使用粒子伪装命中数量。
- 图表仍可点击，键盘可选词，读屏文本始终是最终真实值。

## 数据流与错误处理

`PoetryWorkbench` 继续负责目录与 Tool 请求；Motion Lab 状态只向下传递或通过 Context 读取。组件不得写回后端。地图资源失败、证据不足、空结果和请求错误继续使用现有状态组件；动画层失败或浏览器不支持相关 API 时降级为静态内容。

## 性能与可访问性

- 动画使用 CSS、ECharts 更新和 `requestAnimationFrame`，不新增 Framer Motion、GSAP、Lottie 或远程依赖。
- 同时只运行当前主模式的高强度动画；页面隐藏、组件卸载和切换诗人时清理帧与计时器。
- `prefers-reduced-motion` 和实验室关闭态均绕过 JS 等待，而非仅压缩 CSS 时长。
- 控件最小 44px，焦点可见；遮幅期旧、新场景不会同时进入辅助技术阅读顺序。
- 390×844 不产生横向溢出，不使用大面积 3D 翻转或模糊。

## 测试与验收

- 单元测试：偏好持久化、档位归一化、场景状态机、导航锁、reduced-motion 立即完成、意象选择状态。
- 现有验证：lint、typecheck、全部 Vitest、production build。
- 浏览器验收：3011 端口，1440×900 与 390×844；逐项检查三种模式、三档动画、暂停/继续/重播、诗人切换、键盘、无横向溢出、无可操作控制台错误。
- 原工程保护：验收前后确认原 `apps/agent-ui/web/src`、`data` 和 `output` 修改时间与哈希未变化。

## 完成标准

用户可以打开一个独立副本，在三种主功能中看到各自的复杂标志性动画，并通过 Motion Lab 即时切换“克制 / 电影 / 实验”或关闭动画；所有模式保持真实数据与证据契约、移动端可用、减弱动效可用，且构建和测试通过。
