# 宋版套色行旅刻符：连续路线动画设计

## 目标

修复 Agent UI 路线页的三项体验缺陷：白色气泡式交通标记、无史料连线时的瞬移、导航线与活动线难以区分。所有数据仍由 Python Tool 输出；视觉转场必须显式声明不构成史实路线。

## 已确认事实

- 六位诗人共有 122 幕，其中 113 幕可定位。
- 播放顺序中有 100 组“相邻且两端可定位”的场景。
- 当前严格史料连线 51 条，另外 49 组会直接瞬移。
- 当前 Guide 与 Active 线的实测 RGB 距离约 4.1；58px 标记会覆盖短路线约 78%。

## 数据架构

'routeSegments' 保留现有 51 条严格史料连线，不改变史料语义。Python Tool 在筛选场景之后新增 'visualTransitions'，只补“相邻、两端可定位、且不存在严格连线”的 49 组缺口。

视觉转场字段：

~~~json
{
  "from_id": "SCENE_A",
  "to_id": "SCENE_B",
  "coords": [[LON_A, LAT_A], [LON_B, LAT_B]],
  "kind": "visual_transition",
  "certainty": "not_asserted",
  "historical_claim": false,
  "gap_reason": "adjacent_locatable_scene_gap",
  "transport_mode": "journey",
  "transport_label": "山径行旅",
  "transport_basis": "两幕均有作品节点坐标；实际行路与交通方式未载，仅作镜头转场。",
  "transport_certainty": "unspecified"
}
~~~

严格史料段始终优先。视觉段不调用交通词分类器，不进入“史料路线”计数。任一端缺坐标时不生成视觉段，界面直接切幕并说明“缺少可定位坐标”。

## 播放层

前端将史料段与视觉段解析为 'JourneyLeg'：

- 'historical_route'：正向使用 Tool 的史料交通方式和依据。
- 'camera_transition'：使用山径行旅刻符，文案为“镜头转场 · 路径未载”。
- 反向回看史料段按 'camera_transition' 播放，不把正向史料依据冒充返程依据。
- 减少动态效果模式直接抵达，但内容、路线说明和控制均保留。

路线几何由同一组采样点同时驱动 ECharts 线条与 DOM 标记，避免线和图标分离。采用确定性的二次贝塞尔弧线、28 个采样点和 'easeInOutCubic'；时长按距离限制在 3200–5500ms。

## 交通刻符

新建透明底的“宋版套色·行旅刻符”，不再使用 Lucide 人物、汽车、白圆、V 形尾针或重阴影。

| 模式 | 轮廓 | 主色 |
|---|---|---|
| boat | 江船 | 靛青 |
| horse | 骑马侧影 | 深朱砂 |
| carriage | 双轮篷车 | 墨色，朱砂轮毂 |
| walk | 持杖旅人 | 玉色 |
| journey | 山口曲径 | 墨色，朱砂终点 |

定位盒 36×42px，图形最大 29×27px，SVG 的 '(18,38)' 与地图坐标重合。外层只做路线位移；内部船纹、马腿、车轮、衣摆各自做不超过 1px 的微动。抵达时播放一次 220ms 落印扩散环，随后静止。

## 地图线条

- 史料路线：靛青实线，2.4px，opacity 0.78。
- 视觉转场：灰金点线，1.7px，opacity 0.62。
- 当前活动路线护线：浅纸色 7px，opacity 0.9。
- 当前活动路线主线：朱砂 5px，opacity 0.96。
- 已完成路线：诗人主题色 3px，opacity 0.82。

Guide 与 Active 的颜色距离必须大于 45；刻符视觉宽度不超过短路线长度的 45%。图例明确区分“史料路线”和“路径未载的镜头转场”。

## 状态文案

- 史料段：'舟船 · 史料有据' 等。
- 视觉段：'镜头转场 · 路径未载'。
- 缺坐标：'地点坐标未定，已切换到目标诗篇。'
- 页面方法说明：视觉转场仅连接作品节点坐标，不表示真实道路、交通工具或旅行速度。

## 验收

1. 李白 01→02 进入 travelling，不再瞬移，并显示视觉转场文案。
2. 李清照 13→14 仍为舟船史料段。
3. 白居易含缺坐标的相邻场景仍直接切幕并提示。
4. 图标透明底、五类轮廓可辨、坐标点重合。
5. 导航线在移动前、移动中、移动后均可见。
6. 1440×900、700×900、390×844 无页面横向溢出、无控制台错误。
7. 原 29–38 号离线展项不受影响。
