# 宋代零 person-event 诗人手工补采：石延年、朱淑真

采集日期：2026-08-09  
数据文件：`data/candidates/manual_source_evidence_song_zero_event.jsonl`

## 1. 口径

- 本批只补采石延年、朱淑真两人，不改既有自动采集文件、`data/reviewed/` 或 `output/`。
- `event_candidate` 必须由**同一来源、同一依据**同时明确承载人物、时间与地点。时间只有朝代或相对时点时会降级，并在 `notes` 中声明粒度。
- 生卒、籍贯、官职、地址等分离字段不互相拼接。来源仅记“某人某年生”与“某人籍贯某地”时，仍为 `clue_only`。
- 墓地后验、他人在某地传抄作品、其父任官地、辑者闻词地，都不是诗人本人行迹。
- `fact_grade`：A=同时代一手文献（墓表、祭文）或日期明确的编年条；B=正史、权威目录中直接可核的书目事实或稳健学术结论；C=后出方志、聚合数据库、带推断的学术判断，或权威目录中仍有争议的生平说法；D=互相冲突且缺原始纪年的规范值。

石延年的两条“河东”记录分别来自《续资治通鉴长编》和《宋史》，属于同一任务簇；因此事件证据记录为 6 条，但去重后为 5 个事件簇。朱淑真的唯一事件候选是学者依据诗作内证推定的“1138 年以后临安西湖”区域事件，仍需人工审核。

## 3. 石延年：可成事件

1. **1041 年卒于京师**：欧阳修《石曼卿墓表》同句具年、月、日和卒地，A 级。
2. **卒后三十七日葬太清先茔**：同一墓表给出相对时间和墓地，A 级；“太清”尚未落实坐标。
3. **1035 年落职通判海州**：《续资治通鉴长编》卷一百十六景祐二年二月丁卯条，A 级。
4. **1040 年赴河东路计置催促粮草**：《长编》卷一百二十七康定元年四月条，A 级。
5. **元昊反后命往河东籍乡兵**：《宋史》卷四百四十二，B 级，与上条为同一行程簇的正史互证。
6. **真宗时知金乡县**：《山东通志》给出真宗朝与金乡县，C 级；时间跨度 997—1022，只能作粗粒度候选。

CBDB、上海图书馆 RDF 与 CText 数据维基都找到了石延年规范实体，但其中生卒、籍贯和任官多为分离字段，未据此增造路线。《祭石曼卿文》仅后验太清墓地，属于身后线索。

## 4. 朱淑真：争议必须显式保留

朱淑真缺少可直接使用的宋代墓志、正史本传和确定生卒纪年。当前来源形成多组互相冲突的说法：

### 4.1 生卒与时代

- MQWW、CBDB、上海图书馆 RDF 使用 `1095—1131` 或 `fl.1095—1131`。
- CText 数据维基摘要使用 `1135—1180`。
- 缪钺论文明确说“生卒年无从确考”，再以作品内证推测约 1119 年生、1163 年以后数年卒。

这些数值都保留为线索，不选一个写成确定生卒。唯一事件候选来自缪钺对《夜留依绿亭》与西湖诗群的论证：作品应在绍兴八年（1138）临安定都以后，地点在临安西湖一带。它是 C 级推断，只能作为待审候选。

### 4.2 籍贯

- MQWW：盐官（今海宁）。
- CBDB / 上海图书馆 RDF：钱塘为基本地址，盐官为另一籍贯。
- 《四库全书总目提要》卷一百七十四：钱塘女子。
- 同书卷一百九十九：海宁女子。
- CText 摘要还并列歙州说。

籍贯不是迁徙事件，且来源冲突，所以全部为 `clue_only`。

### 4.3 家世、婚姻、作者身份

- 《四库全书总目提要》卷一百九十九以朱子年谱、世系反驳“朱文公侄女”说，认为可能是依附盛名。
- 卷一百七十四采用“嫁为市井民妻”的旧说，同时批评田艺蘅《纪略》中的部分叙述近于依托。
- 《生查子·元夕》的作者归属有朱淑真、欧阳修两说；四库馆臣采用欧阳修说。作品归属争议不能反推行迹。
- 中央研究院《断肠词》典藏目录中的临安、吴中、宛陵，涉及传、辑、序及版本流转，不代表朱淑真本人到过这些地方。

### 4.4 明确排除的“伪路线”

- 魏仲恭在武陵旅邸闻人传词：是辑者所在地，不是朱淑真所在地。
- 《璇玑图记》所谓“家君宦游浙西”：地点属于其父，且文献真伪、纪年都受质疑。
- “墓在青芝坞”、父为某人、夫为某人、往来吴越荆楚等现代推考或地方传说：本批未取得同据时地原始证据，未入事件候选。

## 5. 负面检索与访问限制

- DILA 人名 API 对“石延年”“朱淑真”均返回 `null`；DILA 以佛教人物与佛典来源为主，这个结果只记为“未命中”，不解释为人物不存在。
- 上海图书馆开发接口需要 API Key；本批使用其公开 RDF 实体页/N-Triples，并保留实体 ID。
- CText 数据维基网页有时触发 403/人机验证；通过其公开实体检索结果核对 ID，并将聚合摘要降级为 C/D 级线索。
- 朱淑真的数据库生卒值彼此冲突；任何页面在后续展示时都应显示“争议/推定”徽章，不得直接进入确定路线。
