## 四、每张导读卡的写作规范

### JSON 条目格式（batch 文件中的每个 item）

```json
{
  "poet": "李白",
  "title": "望庐山瀑布",
  "summary": "紫烟银瀑一望间，把山写成了天上的事。",
  "guide": "先看颜色和光：日照香炉，紫烟蒸腾……（150-240字向导口吻赏析）",
  "origin": "通说此诗作于开元十三年（725）前后……（80-160字，必须「通说」开头）",
  "confidence": 0.95
}
```

### 字段要求

| 字段 | 字数 | 风格要求 |
|------|------|----------|
| `poet` | — | 与 poems 表 `poet` 字段**逐字一致**，包含异体写法 |
| `title` | — | 与 poems 表 `title` 字段**逐字一致**（注意库内可能含错别字，不要擅自纠正） |
| `summary` | ≤30 字 | 一句话抓住全诗最核心的画面或情绪，要有"人味" |
| `guide` | 150–240 字 | **向导口吻**，先画面后手法。禁止出现字段名（如"这首诗表达了"）。禁止机器腔、模板句。要像站在读者身边低声讲解 |
| `origin` | 80–160 字 | **必须以「通说」开头**。交代创作背景和作年/作地。**禁止虚构史料出处、页码、日期**。有事实则按层级引用（如"本库人工核验系年约1121年、作地昌乐（A/B级）"），无事实则写"本库暂无核验条目" |
| `confidence` | 0.5–0.99 | 越生僻的诗越低。名篇 0.85–0.95，常见 0.7–0.85，冷门 0.5–0.7 |

### 写作红线（绝对不可违反）

1. **不调用任何外部 LLM API** ——所有内容由你本人撰写，不可转包给其他模型
2. **不改动 `data/reviewed/` 目录和既有数据**
3. **不把"通说"写成"史实"** ——origin 永远是学术界的普遍看法，不是定论
4. **不复制既有卡片改字数** ——每首必须重新写，禁止从 gpt-5.4-mini 的卡里复制后微调
5. **不虚构参考文献** ——不编造页码、出处、具体日期
6. **批次号必须顺延** ——已完成 batch_001 到 batch_022，下一批从 batch_023 开始，不可重写已完成批次

## 五、工作流程（每批 30 首）

### 第 1 步：选诗

```bash
cd "D:/game存档/诗行万里2/诗行万里"

python -c "
import sqlite3, json
conn = sqlite3.connect('output/assets/knowledge/poetry_knowledge.sqlite3')
cur = conn.cursor()
rows = cur.execute('''
    SELECT p.poet, p.title, p.body
    FROM analyses a JOIN poems p ON a.poem_id = p.poem_id
    WHERE a.kind = 'poem_guide' AND a.model = 'gpt-5.4-mini'
    AND p.poet || p.title NOT IN (
        SELECT poet || title FROM poems p2
        JOIN analyses a2 ON a2.poem_id = p2.poem_id
        WHERE a2.kind = 'poem_guide' AND a2.model = 'zcode-assistant-glm5.3'
    )
    ORDER BY RANDOM()
    LIMIT 30
''').fetchall()
json.dump([{'poet':r[0],'title':r[1]} for r in rows], open('tmp/_bNN.json','w',encoding='utf-8'), ensure_ascii=False, indent=2)
print(f'selected {len(rows)} poems')
for r in rows:
    print(f'  {r[0]}《{r[1]}》')
conn.close()
"
```

> `NN` 替换为批次号（从 023 开始）。

### 第 2 步：逐首撰写

为选出的 30 首诗各写一张导读卡。撰写时需要：
- **查库获取全诗正文和事实背景**：

```bash
python -c "
import sqlite3, json
conn = sqlite3.connect('output/assets/knowledge/poetry_knowledge.sqlite3')
cur = conn.cursor()
# 替换诗人和诗题
row = cur.execute('''
    SELECT p.body, a.evidence_json, a.payload_json
    FROM poems p
    LEFT JOIN analyses a ON a.poem_id = p.poem_id AND a.kind = 'poem_guide' AND a.model = 'gpt-5.4-mini'
    WHERE p.poet = ? AND p.title = ?
''', ('诗人姓名', '诗题')).fetchone()
if row:
    print('=== 全诗正文 ===')
    print(row[0])
    ev = json.loads(row[1] or '[]')
    pl = json.loads(row[2] or '{}')
    print('=== 旧卡 evidence ===')
    print(json.dumps(ev, ensure_ascii=False, indent=2))
    print('=== 旧卡 origin ===')
    print(pl.get('origin', '无'))
conn.close()
"
```

- 参考旧卡的事实信息（evidence），但**必须用自己的语言重写** guide 和 origin
- 按 §四 的格式规范产出 JSON 条目

### 第 3 步：组装 batch 文件

将 30 个 item 组装为：

```json
{
  "batch": "batch_023",
  "author": "接手助手（可替换为你的名称）",
  "policy": "summary≤30字；guide 150-240字向导口吻；origin 80-160字以「通说」开头；置信为撰写者自评",
  "items": [
    { "poet": "...", "title": "...", "summary": "...", "guide": "...", "origin": "...", "confidence": 0.85 },
    ...
  ]
}
```

保存到 `data/assistant_guides/batch_023.json`。

### 第 4 步：校验

```bash
python -c "
import json
d = json.loads(open('data/assistant_guides/batch_023.json', encoding='utf-8').read())
errors = []
for i, item in enumerate(d['items']):
    if len(item.get('summary','')) > 30: errors.append(f'item {i} summary超长: {len(item[\"summary\"])}字')
    g = item.get('guide','')
    if len(g) < 150 or len(g) > 240: errors.append(f'item {i} guide长度异常: {len(g)}字')
    o = item.get('origin','')
    if not o.startswith('通说'): errors.append(f'item {i} origin未以「通说」开头: {o[:20]}')
    c = item.get('confidence',0)
    if c < 0.5 or c > 0.99: errors.append(f'item {i} confidence异常: {c}')
if errors:
    for e in errors: print('ERROR:', e)
else:
    print(f'全部 {len(d[\"items\"])} 条校验通过')
"
```

guide: 先看颜色和光：日照香炉，紫烟蒸腾，瀑布像一匹白练挂在山前——一个「挂」字，把奔流的水定成了静止的画。后两句忽然放大：飞流直下三千尺，已是夸张；再疑心是银河从九天落下，就把庐山接进了天上。李白的夸张从不是虚张声势，他先给你一个可信的远景（遥看、挂前川），再一步跨到宇宙尺度，让你顺着他的视线完成这次跳跃。读到「疑」字要停一下：他自己也半信半疑，这正是全诗最真的地方。
