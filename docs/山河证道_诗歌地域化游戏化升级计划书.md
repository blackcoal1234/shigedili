# 《诗行万里》升级计划书：诗歌地域化研究 × 游戏化学习（山河证道）

> 版本：v1.0（2026-08-16）
> 范围：在现有数据分析管线与展项体系之上，确立"诗歌地域化"研究主题，新增"山河证道"游戏化学习层，整合静态展项与 Agent 工作台为统一体验动线，并完成视觉资产与工程收尾。

## 二、主题定位：诗歌地域化

### 2.1 核心思路——把主角从"诗人"换成"地方"

现有地理展项均为诗人视角（诗人怎么走、在哪里遥想）。地域化研究反转视角，回答：**每个地方被写成了什么**——意象与情感如何随地理变化；同一人换地后诗风如何突变；哪些地方被亲历书写、哪些被远方想象。

### 2.2 三个研究产出

| # | 产出 | 内容 | 数据来源 |
| --- | --- | --- | --- |
| R1 | **地域诗歌画像** | 以今地/区域为单元：写过它的诗数、诗人、年代分布、高频意象、平均情感值、季节词分布，产出"地方诗格档案卡"（例：扬州——意象前五：月、桥、琼花；情感值偏高；多写于路过与遥想） | 事实包作地 + 逐行意象分析 + `place_dict` 落点 |
| R2 | **意象 × 地域矩阵** | 量化意象的地域归属（大漠孤烟→西北，画船藕花→江南），产出热力图/弦图，作为地域化最直观的学术证据 | 164,279 条逐行分析 × 作地标注 |
| R3 | **在地率指标（本项目独有）** | 某地的诗中"身在此地写此地" vs "身在别处想此地"的比例——"地方的被想象率"；配合 viz_16 创作中心南移时间轴（安史之乱、靖康两个断点）形成完整叙事 | viz_32 身/心双层数据、行旅事件、事实包 |

**方法纪律**：124 首严格作地的诗做城市级统计偏少，统计必须分层标注证据等级（严格核验 A/B 级 vs 行旅推断）；区域级大颗粒统计可用行旅事件与遥想数据补充。禁止用推断数据冒充核验数据。

## 三、游戏层设计：山河证道

### 3.1 设计原则

**题即论据、关即区域、奖励即结论**——玩家每答一题，等于亲身复现一次"从意象推断地理"的地域化论证；玩完一章，等于读完一份研究结论。游戏是研究的群众版，不是贴皮。

### 3.2 核心玩法：猜创作地（诗词版 GeoGuessr）

- 上半屏诗句（隐去题目与作者），下半屏中国地图，玩家点击创作地；
- 计分：`5000 × e^(-距离km / 300)`——300 公里内高分，跨大区锐减；
- 难度分级：意象显性（大漠、孤烟、荷花、画船）为低难度题，意象含糊为高难度题，由逐行意象分析自动定级；
- 答后揭示证据链（见 3.5 学习卡），每题的揭示就是一次地域化论证。

### 3.3 题型体系（六 + 一）

| # | 题型 | 说明 | 数据来源 |
| --- | --- | --- | --- |
| Q1 | 猜创作地 | 核心玩法，见 3.2 | 事实包（作地）+ `place_dict` + GeoJSON |
| Q2 | 身在此地还是遥想彼地 | "写这首金陵诗时，诗人在金陵还是在别处想念金陵？"——本项目独有题型，直接来自"在地率"研究 | viz_32 数据 |
| Q3 | 地名飞花令 | 给一字/一地名，四选项挑出真正含它的诗句，干扰项从语料自动抽取 | 20,437 首语料 |
| Q4 | 四字猜诗人 | viz_34 现成 12 题题库化、按章分配 | viz_34 |
| Q5 | 意象归乡 | "哪组意象最不可能出现在江南诗？"或拖拽意象入边塞/江南框 | 意象 × 地域矩阵（R2） |
| Q6 | 章末 Boss：同龄对读 | "公元 759 年，李白流放夜郎途中，同时刻的杜甫在做什么？"四选一 | viz_36 同龄泳道、viz_33 |
| Q7 | 古今地名连线（轻题型） | 长安↔西安、姑苏↔苏州、汴京↔开封配对，强化教学点 | `place_dict` 别名词表，白捡题型 |

### 3.4 章节结构（5 + 1 章）

| 篇章 | 地域 | 主角诗人 | 意象/命题 | 开卷动画（Seedance） |
| --- | --- | --- | --- | --- |
| 第一章 长安篇 | 关中 | 杜甫、李白 | 都城气象与幻灭 | S14 彩云白帝 / S07 云隐庐山 |
| 第二章 边塞篇 | 西北 | 岑参、王昌龄 | 意象最烈的地域样本 | S22 河岳南望 / S39 秦州月白 |
| 第三章 巴蜀篇 | 蜀道、夔州 | 李白、杜甫晚年 | 险峻地理与诗风 | S14 / S21 九州待晓 |
| 第四章 江南篇 | 杭州、苏州 | 白居易、苏轼 | 水乡意象的另一极 | S09 西湖晴雨 / S47 临安黄昏 |
| 第五章 贬谪篇 | 黄州、柳州、永州 | 苏轼、柳宗元、刘禹锡 | **地域化黄金素材：人没变只有地变了，控制变量天然成立** | S31 雪泥鸿爪 / S19 缺月疏桐 |
| 终章 山河 | 全国 | 88 人 | 集齐诗印解锁总图 + 地域画像总览 | S21 九州待晓 |

每章流程：**开卷动画 → 3~5 关（每关一题）→ 章末"地方诗格档案卡"（即 R1 研究结论）**。章末奖励就是研究发现，评委看到即懂全项目。

### 3.5 三级提示阶梯（教学核心）

每用一级，本题得分上限打折；**前 3 题为教学关，提示免费**。

| 级别 | 内容 | 得分上限 | 生成方式 |
| --- | --- | --- | --- |
| 一级·省份圈定 | "此诗写于今陕西或甘肃境内"（正确省份 + 邻近干扰省份） | ×0.7 | 自动 |
| 二级·古今地名对照 | 诗中"长安"→"即今西安，陕西关中"；诗中无地名时自动换成"生平定位"（"写此诗时诗人刚离京贬谪途中"） | ×0.5 | `place_dict` aliases 扫描，全自动；生平定位来自行旅事件 |
| 三级·意象证据 | "'孤城''落日''羌笛'组在意象矩阵中 78% 出现于西北边塞诗" | ×0.3 | 意象 × 地域矩阵（R2）自动统计 |

### 3.6 答题后学习卡（五层，学习发生地）

1. **对照地图**：玩家落点 vs 正确地点连线 + 距离标注；
2. **全诗 + 题目 + 作者**（答题时隐去，此刻揭开）；
3. **证据链逐条讲**：诗中每个地域性意象单独列出并解释指向；
4. **古今地名对照表**：本诗全部地名 → 今地 → 省份；
5. **赏析双栏**：
   - **考据栏**：人工核验事实（作年、作地、生平阶段），标 A/B 证据等级——事实包现成；
   - **导读栏**：LLM 生成背景与赏析，**显著标注"AI 导读，非考据"**——两栏并置既解决富背景 0/60 的覆盖缺口，又守住"模型生成不得冒充验收"的门禁，反而成为项目诚实性的加分项；
6. 尾部"**同地再读一首**"按钮 → 该地地域画像/相关诗，把单题学习串成"一个地方的诗"。

配套：**错题诗签**——答错或距离超阈值的诗自动收入"行囊"，章末弹出复习，形成学习闭环。

### 3.7 成长系统（轻量）

- **诗印集章**：每章一枚，视觉复用 Agent 工作台宋版套色刻符（`TransportGlyph`）风格，零新设计成本；
- **诗人图鉴**：答对解锁诗人卡，卡面用生命卷第一人称叙事碎片——把"22/88 生命卷"从空态包袱变成解锁奖励；
- **玩家行旅地图**：每答对一地点亮一地，与 viz_15 诗人行旅图互为镜像（"诗人行万里，你行诗万里"）；
- **称号段位**：行客 → 游学士 → 供奉 → 诗伯，按总分授予；
- **押注机制（可选）**：答题前可押注双倍，答错归零——一行代码级别，紧张感翻倍。

### 3.8 统一入口（解决"两个世界割裂"）

- **游戏壳即总入口**：玩家从"山河证道"进入；
- **考据馆**：通关一章解锁对应深链（viz_15/16/20/31/32 等），30+ 静态页从"一堆链接"变成"通关后的深度阅读"；
- **Agent = 行囊导师**：卡关可问提示；**离线兜底**——degraded 模式下自动切换为预生成的分级提示卡（每题 2~3 条，随题库一起产出），现场演示零风险；
- **Seedance 17 支精选视频 = 章节开卷动画**（循环铺底、诗句叠加留白区），两个缺口一个方案补齐。

## 五、风险与对策

| 风险 | 对策 |
| --- | --- |
| 严格作地样本少（124 首），城市级统计单薄 | 分层标注证据等级；区域级用行旅+遥想数据补充；页面明示样本量 |
| LLM 导读被误当考据 | 双栏设计 + 显著标注"AI 导读，非考据"；考据栏只放 A/B 级核验事实 |
| Agent 现场降级 | 预生成分级提示卡兜底；演示模式不依赖 key |
| 视频生成质量不达标 / 周期失控 | 17 支按优先级分批；单支不达标降级为静态首帧 + Ken Burns 缓动 |
| 时间不足 | 优先级铁律：**Q1 猜创作地 + 提示 + 学习卡闭环 > 章节结构 > 其他题型 > 视频壁纸**；阶段一独立成立即可演示 |
| 玩法做重失控 | 严守边界（见第六节），一切纯前端本地运行 |

## 六、明确不做的事（边界）

- 不做多人对战、实时联机；
- 不做账号系统、服务器端进度、排行榜后端；
- 不引入新的运行时依赖（游戏沿用 viz_34 本地 JS + ECharts + localStorage 模式）；
- 不用模型生成内容冒充人工核验成果（延续项目门禁）。

---

## 七、成功标准

1. **研究**：R1 地方诗格档案卡、R2 意象×地域矩阵、R3 在地率指标三件产出齐备且证据分级可查；
2. **游戏**：一局 20~30 分钟的完整通关体验，核心闭环（提示 → 猜地 → 学习卡）手感成立；
3. **整合**：单一入口贯穿游戏 → 考据馆 → Agent 导师，静态展项与工作台不再是两个世界；
4. **资产**：17 支 Seedance 开卷动画接入；
5. **工程**：全流程部署可重复、可回滚，仓库干净。

> 一句话总结：把"诗歌地域化"研究做成一场可以通关的旅行——题即论据，关即区域，奖励即结论。
